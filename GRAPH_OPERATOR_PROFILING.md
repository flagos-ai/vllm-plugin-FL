# Runtime Kernel Profiling

The profiling tools support one reproducible workload: 64 concurrent requests
with 4096 input tokens and 256 output tokens per request.

See
[`tools/graph_operator_profile/GRAPH_OPERATOR_PROFILING.md`](tools/graph_operator_profile/GRAPH_OPERATOR_PROFILING.md)
for the graph/eager and plugin/native commands, output formats, and coverage
boundary.
